4. API test reference

This standalone HTML page simulates API responses in the browser. It does not expose real HTTP endpoints. Use the examples below to build Playwright API tests against a mock server you control.

POST /api/payments/qr GET /api/accounts GET /api/accounts/:id/balance POST /api/payments/:id/confirm

Suggested cases: valid amount, zero/negative amount, invalid merchant, sufficient balance, insufficient balance, missing auth, duplicate confirmation, unknown payment ID.
